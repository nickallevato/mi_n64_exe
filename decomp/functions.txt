# Decompiled functions (scripts/decomp_dispatch.py, src/decomp/dispatch.cpp). One per line:
#   name  system  on|off  check|read  [flags]
# state:  on = the decompiled version runs (developer builds), off = the recompiled original runs.
# method: check = run side by side with the original in check mode (MI_DECOMP_CHECK=1);
#         read  = never run twice (e.g. it waits on a message or thread); checked by reading it against the asm.
#         Put the reason on a comment line above a read line.
# flags:  hooks-moved=VRAM.HASH = this mi.us.toml hook now lives in the decompiled C; one per hook, comma-separated.
#         The hash is of the hook's text, so a hook added or changed later fails the build; the error prints the flag.
#         ret64 = returns a 64-bit value (s64, u64, double); the check then also compares r3 and f1/f3.

# loading: Burp archives (decomp/src/loading/burp.c)
# Rom_Read waits on osRecvMesg for each DMA chunk, which can switch to another game thread mid-check. Every
# function below that reads the ROM is read for that reason.

# Only ever called from Burp_FindByName, so it's never checked on its own; Burp_FindByName's check covers it (1122

Burp_GetName        loading  on  read
Burp_FindByName     loading  on  check
# Never called in the 20-level run; checked by reading.
Burp_CopyEntry      loading  on  read
Burp_GetCount       loading  on  check
# Rom_Read (see above).
